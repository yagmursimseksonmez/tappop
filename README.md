# TapPop

A tap-to-pop puzzle with ten levels, built in Unity 6.3 LTS as a UI work sample.

- **Style guide:** https://yagmursimseksonmez.github.io/tappop/
- **Play:** https://yagmursimseksonmez.github.io/tappop/play/
- **Unity project:** https://github.com/yagmursimseksonmez/tappop-unity

Tap two or more touching tiles of one colour to pop them. Where tiles land, four or more of one colour pop by themselves. Ten levels: each asks for a few more tiles in a few fewer moves, and progress and stars are saved in the browser. Pop sounds are synthesised by a script.

Design, tiles and UI: Yağmur Şimşek. Built with Unity uGUI and TextMeshPro, exported to WebGL.
Font: [Geist](https://github.com/vercel/geist-font), SIL Open Font License 1.1 (`assets/fonts/OFL.txt`).
