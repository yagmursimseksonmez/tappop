# TapPop

A one-level tap-to-pop puzzle, built in Unity 6.3 LTS as a UI work sample.

- **Style guide:** https://yagmursimseksonmez.github.io/tappop/
- **Play:** https://yagmursimseksonmez.github.io/tappop/play/

Tap two or more touching tiles of one colour to pop them. Where tiles land, four or more of one colour pop by themselves. Clear 25 red tiles in 20 moves.

Design, tiles and UI: Yağmur Şimşek. Built with Unity uGUI and TextMeshPro, exported to WebGL.
Font: [Geist](https://github.com/vercel/geist-font), SIL Open Font License 1.1 (`assets/fonts/OFL.txt`).
